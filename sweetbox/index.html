How to install the APK

  1. Download
    Tap Download APK above on your Android phone and wait for the file to finish downloading.
  2. Allow the install
    Open the file. If Android asks, allow your browser or file manager to Install unknown apps in Settings, then go back.
  3. Play
    Tap Install, then open Sweet Box and start connecting dots.
Heads up: this is an early beta build. When Sweet Box launches on Google Play, the Play Store version will replace it. You may need to uninstall the beta before installing from Google Play. Requires Android 14 or newer.
